Taskflow

Sistema Avançado de Gestão de Tasks

Uma plataforma web completa desenvolvida para gerenciar demandas de forma eficiente. O sistema apresenta uma modelagem de banco de dados relacional complexa (PostgreSQL) para organizar setores, e implementa Role-Based Access Control (RBAC), garantindo que usuários, gerentes e administradores tenham permissões estritamente adequadas às suas funções. A interface foi construída para ser 100% responsiva utilizando Tailwind CSS.
